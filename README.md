# SuperPrime FDC prototype

A responsive, clickable web prototype based on the provided Figma flow.

The prototype bundles the supplied Merchant 2.0 web fonts and uses the CX Design Library's mobile component specifications and exported assets for buttons, progress bars, radio controls, tiles, inputs, status tags, and navigation.

## Run locally

```bash
python3 -m http.server 5173
```

Open [http://localhost:5173](http://localhost:5173).

Prototype security code: any six digits succeeds; `000000` shows the error state.
